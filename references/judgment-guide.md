# topic｜判断说明（V0.1）

本文件用于按需校准观看理由、回应选择与典型误判，核心流程见 [SKILL.md](../SKILL.md)。

## 构成要素及使用标准


以下是判断依据，不是独立产品模块，不是必须逐项打分的问卷，也不是数学乘法公式。

| 要素 | 真正要判断什么 | 常见误判/边界 |
|---|---|---|
| 真实需求与兴趣 | 有哪些事实支持这个人关心它？是当前任务、长期困扰、阶段性选择，还是会被新信息激起的兴趣？ | 不是所有内容都要解决痛点；不能用低点赞倒推出没有需求。 |
| 自我相关与具体处境 | 观众在哪里认出了自己、想成为的人、关心的人或群体？ | 人口标签不是处境；钱多不等于怕贵；付款人不总是使用者。 |
| 获得与省力 | 能得到什么、少付出什么，表达是否让人理解？ | 低成本是预期，不是承诺零努力、人人赚钱、保证结果。 |
| 避损与控制 | 什么具体的不确定、担忧或损失与这个人相关？ | 不能无证据制造医疗、财富或家庭恐慌。 |
| 好奇与认知缺口 | 熟悉的认知、经验或物件发生了怎样值得了解的变化？ | 陌生名词、夸张语气并不自动产生兴趣。 |
| 身份、比较与关系 | 自我认同、想靠近的生活方式、群体关系、亲情等是否自然成立？ | 羡慕贵妇可以是创意角度，但不能编她们的消费行为。 |
| 具体价值 | 看完能取得答案、标准、资源、示范、情绪、审美、故事或谈资中的什么？ | “提升认知、很有价值、了解一下”不是充分说明。 |
| 感知与理解成本 | 仅看到真正对外的选题表达，能否意识到看下去值得？ | 不能用隐藏在“实际讲什么”中的优点替标题补分。 |
| 可呈现性 | 有没有可用或能制作的画面、声音、动作、物件、人物或对比？ | 不要求每题视觉奇观；有画面也不证明实际留存。 |
| 内容兑现 | 实际内容能否交付标题中让人期待的东西？ | 强表达不等于可以编案例、价格、疗效、社会证明。 |

### 一次判断的轻重顺序

1. **不可破的边界**：任务目标不偷换，关键事实不编造，承诺不失配。
2. **核心质量**：具体的人为什么看，实际内容能给他什么，回应是否适合其处境。
3. **表达质量**：观看价值是否容易感知，语言是否具体，有没有值得继续的原因。
4. **整组质量**：重复、同质化、偏科和业务目标匹配。

不要把“安全无误”直接等同于“值得看”；也不要让追求刺激抵消真实性。


## 回应选择


对最重要的需求或兴趣，在必要时比较2—3种回应；不对每题穷举十种方案。

可选：直接答案、真实证据、结果/体验比较、实际演示、资源/清单、人物故事、观点判断、娱乐/审美体验等。

判断哪个最能让用户得到他期待的东西，同时理解与行动成本适合他。

- 害怕学不会，可能需要看真实作品，而不是学习一套自我考核体系。
- 真的想判断适合哪种岗位，简单体验任务可能比故事更有用。
- 愿意花钱让父母舒服，可能需要看到照顾如何发生，不需要先学会筛选技术名词。
- 同样的专业问题，有些适合比较画面，有些适合明确答案，有些适合反认知解释。

**没有固定“证据 > 比较 > 演示 > 方法”的优先级。**无证据时不能为了套顺序而编证据；也不能一味把复杂专业判断重新交给小白。

**内部产物**：选题核心 + 最适合的内容承载方式 + 支撑来源或可制作计划。
